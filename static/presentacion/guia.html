Introducción y recorrido por la interfaz

“Desarrollamos una aplicación web que estima la probabilidad de aprobación usando 6 variables académicas y Cálculo Diferencial: combinación lineal, sigmoide, límites, continuidad y derivadas.”

Encabezado

  • Temas (Oscuro / Claro / Rosa) — solo cambian colores, no el cálculo

Resultado (gauge)

  • Veredicto — ≥ 70 % aprueba probable; ≥ 50 % en riesgo; < 50 % reprobación
  • Fórmula — z = … → σ(z) = …
“El servidor calcula z, aplica la sigmoide y devuelve un porcentaje entre 0 y 100.”

Modelo matemático y sigmoide

1. Normalización (servidor Python)

asistencia÷100 · promedio÷100 · horas÷40 · trabajos÷10 · participación÷5 · concentración÷5

2. Combinación lineal

z = −7,2 + 2,5·asist + 3,0·prom + 1,8·horas + 1,5·trab + 1,2·part + 1,0·conc

3. Función sigmoide

σ(z) = 1 / (1 + e^(-z))
Probabilidad % = σ(z) × 100
“La sigmoide acota entre 0 % y 100 % (límites). Al mover sliders el cambio es gradual (continuidad).”

Derivadas, sensibilidades y factores

σ'(z) = σ(z) · (1 − σ(z))
∂σ/∂xᵢ = wᵢ · σ'(z)
Sensibilidad (app) = wᵢ · σ'(z) · 100
“Las barras muestran cuánto mueve la probabilidad cada variable. Promedio e Asistencia impactan más. P·(1−P) es máximo cerca de P ≈ 50 %.”

Análisis de derivadas (barras)

Orden típico de impacto: Promedio → Asistencia → Horas → Trabajos → Participación → Concentración.

Factores identificados

  • Positivos (✔) — variables sobre umbrales favorables
  • Negativos (✖) — riesgos detectados (asistencia baja, poco estudio, etc.)
